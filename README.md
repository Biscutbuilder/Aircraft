
This Project is a ESP32 controlled Fixed winged aircraft. This project will use ESPNOW to have one ESP32 used as a remote controller for
another ESP32 inside of the Aircraft, that controls the flight surfaces and maybe even data collection from sensors.
The Project is between the design and construction phase. Most electronic systems work but the following items need to be made: Control Surfaces (not including servos), Wing Spars, Wing Frame pieces, Airframe, Ground Controller, ESC+BLDC Motor, and more. Each one of the listed parts will connect to each other to make a frame of a wing, which is often used in real planes, rather than just a one or two piece wing. The wing frame will then be covered in a light weight material, (I have this Styrofoam and cloth mix over thing that I will use) to create a smooth completed wing. The ESP32 that is responsible for receiving commands from the ground, will control 4 servo motors and a ESC connected to a BLDC motor. The 4 servos are to control the 3 axis' of flight, yaw, pitch and roll. 2 servos will control the allerions which will give the plane control of roll. 1 servo will control the elevators which will give the plane control over pitch, and 1 servo will control the rudder which allows the plane control over yaw. The ESC and BLDC motor will be front facing, making the aircraft a tractor configured aircraft, meaning the engine is at the front of the plane and is pulling it. The aircraft will also have short, strong, unretractable landing gear to allow the aircraft to takeoff without any human assist other than using the ESP32 controller that uses ESPNOW to communicate with the ESP32 inside the aircraft.
